# Tools

A collection of small personal tools. Each directory is an independent project.

| Tool | What it does |
|---|---|
| [claude-usage](claude-usage/) | Browser dashboard for Claude Code token usage |
| [youtube-downloader](youtube-downloader/) | Multi-threaded YouTube downloader built on `yt-dlp` |

Older one-off scripts live in [`archive/`](archive/). They are kept for reference, not as the supported versions.

Design notes for larger tools go in [`docs/superpowers/`](docs/superpowers/).
