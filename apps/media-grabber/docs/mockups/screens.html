1.2 Home — link resolved (runway + table)
After the first Grab: paste field + runway, no kicker or step cards. Slots are Link · Type · Format · Language · Save to (SkinnedSegment / SkinnedPicker). Link shows the resolved title. Quality ladder drops 360, adds "Best available". Save-to always seeded — here to Downloads. Failed rows read a one-sentence reason; a non-recoverable class (private / removed / geo-blocked) disables Retry (↻). A retrying row shows Retrying — attempt N of M with no position badge and no countdown (the live m:ss lands in a later phase). Queued shows queued · #N and force-start (⏫). The Show-log action (📄) is on every row whose job has run. A completed row served lower than requested shows 1080p → 720p.
(the live backoff countdown, the cooldown health chip + banner, and the success toast arrive in later phases)

§7 About
7.1.1 About — the app, before an app-update check has run
Top-level nav slot freed by demoting Diagnostics (6.1) — About is a destination most users open at least once, unlike Diagnostics. Same fixed-rail-plus-scrolling-pane shell as Preferences, two tabs instead of seven panes. HealthStrip stays global chrome. Every version + every action button lives here, never in Preferences → Updates (settings only, §3.5). Button verb tracks certainty: MediaGrabber's own release check needs GitHub Releases (§10.2) and is genuinely unresolved until it returns, so it reads "Check for updates"; yt-dlp's drift check is a local version-compare, always immediately certain, so it never shows this middle state.
