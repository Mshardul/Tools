First run

Let’s get you set up.

MediaGrabber uses a few free command-line tools to do the actual downloading. One-time setup — about two minutes.

✓

Homebrew

Found at /opt/homebrew/bin/brew.

2

Downloader + media tools

Installs yt-dlp and ffmpeg. Required.

brew install yt-dlp ffmpeg
3

Bot-check shield

Installs the proof-of-origin helper so YouTube downloads don’t get blocked. Recommended.

pipx install bgutil-ytdlp-pot-provider
4

Test run

We’ll grab a few seconds of a known video to confirm everything works.
