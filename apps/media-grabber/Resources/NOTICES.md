# Included tools

MediaGrabber includes these tools. They are not downloaded from Homebrew.

- yt-dlp, the Unlicense. https://github.com/yt-dlp/yt-dlp
- ffmpeg 7.1.1, built from https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz with `--disable-gpl --disable-nonfree` and libmp3lame. ffmpeg is LGPL 2.1 or later.
- LAME 3.100, LGPL, used only to build the mp3 encoder into ffmpeg.
- Node.js 22, the MIT license. Only the `node` program is included.
- The YouTube check helper, version 2.0.2, from https://github.com/Brainicism/bgutil-ytdlp-pot-provider
